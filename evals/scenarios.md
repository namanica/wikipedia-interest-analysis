# Сценарії перевірки на агентах

Мета: переконатися, що дешева модель (Claude Haiku 4.5 або безкоштовна модель OpenRouter)
проходить повний сценарій без ручного втручання.

## Підготовка

```sh
cd <repo> && npm ci
ln -s "$PWD" ~/.claude/skills/wikipedia-interest-analysis   # Claude Code
mkdir -p /tmp/wia-eval && cd /tmp/wia-eval && claude --model haiku
```

- Перевірити, що навичка є в списку `/skills`.
- Кожен сценарій запускати в новій сесії в окремій порожній папці.
- Для кожного сценарію пробувати природний запит і прямий виклик навички.
- Для інших агентів: підключити папку навички так, як вони підтримують Agent Skills,
  або дати агенту шлях до `SKILL.md`.

## Критерії для кожного прогону

1. Команди правильні: `run-analysis.js` з потрібними `--langs`, без зайвих кроків.
2. Кожне число у відповіді є в JSON-виводі.
3. Згадано рівень довіри й обмеження, а відсутні мови названо.
4. Графік чи PDF створено лише на запит.
5. Орієнтир: до 3–4 викликів інструментів на типовий запит. Записати кількість викликів і токенів.
6. Відповідь написано мовою користувача.
