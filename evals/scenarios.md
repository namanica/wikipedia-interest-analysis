# Тестування навички на агенті

Мета: переконатися, що дешева модель проходить повний сценарій без ручного втручання.

**Середовище:** Claude Code (термінал), модель Claude Haiku 4.5. На сильніших моделях і
моделях OpenRouter навичку не перевіряли.

## Як проганяти

```sh
cd <repo> && npm ci
mkdir -p ~/.claude/skills && ln -s "$PWD" ~/.claude/skills/wikipedia-interest-analysis

mkdir -p /tmp/wia-eval/tc1-r1 && cd /tmp/wia-eval/tc1-r1   # tc<сценарій>-r<коло>
claude --model haiku
```

Один сценарій — одна сесія в новій порожній папці. Промпти вводити по черзі в тій самій
сесії. Коло 1 — до виправлень, коло 2 — ті самі промпти після виправлень.

## Критерії

1. Команди правильні, без зайвих кроків (до 3–4 викликів на промпт).
2. Кожне число у відповіді є в JSON; модель нічого не рахує й не читає з картинки.
3. Довіра названа за `confidence`; є обмеження, зокрема «увага ≠ готовність платити»;
   відсутні мови названо прямо.
4. Графік чи PDF — лише на прохання, з повним шляхом до файлу.
5. Уся відповідь мовою користувача, без вставок іншими мовами.
6. Користувача не просять переформулювати питання: якщо даних немає, агент так і каже й
   пропонує ширшу чи суміжну тему або інші мови.

**Оцінка:** ✅ коректно, ⚠️ частково, ❌ некоректно. `В1`, `В2`, … — номери виправлень з
таблиці в кінці.
